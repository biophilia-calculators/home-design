Work out exactly how many rolls you need — walls, doors, windows and pattern repeat all accounted for.

How to Use This Calculator

  1. Add each wall — enter the length and height in centimetres for every wall you're papering. Measure each wall separately for the most accurate result.
  2. Add doors and windows — these are deducted automatically from your total paperable area.
  3. Choose your roll size — pick a standard roll or set a custom width and length.
  4. Set the pattern repeat — larger repeats need extra wastage allowance to align the pattern.
  5. Read your results — total rolls needed and paperable area update instantly on the right.
